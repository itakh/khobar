# KHOBAR · tampilan (GitHub Pages)

Tampilan aplikasi KHOBAR. Data tetap di Google Sheet lewat Apps Script.

- `index.html` diambil dari aplikasi: Pengaturan → Tampilan di GitHub Pages → Unduh index.html, lalu unggah menimpa berkas ini.
- `ikon-*.png`, `favicon-48.png`, `manifest.webmanifest`, `sw.js` = ikon tab, ikon layar utama, dan pemasangan sebagai aplikasi. Cukup sekali; tidak perlu diganti saat update.
